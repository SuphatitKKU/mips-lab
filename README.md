# MIPS Lab

เว็บแอปฝึก C ⇄ MIPS และ Z80 (React + TypeScript + Vite, backend เป็น Node + SQLite) สร้างตาม design handoff "Modernist MIPS Lab v3"

## เริ่มใช้งาน

ต้องใช้ Node 22.5 ขึ้นไป (ใช้ `node:sqlite` ที่มากับ Node)

```bash
npm install
cp .env.example .env   # ใส่ GOOGLE_CLIENT_ID (ดูหัวข้อด้านล่าง) — ไม่มีค่านี้จะล็อกอินไม่ได้
npm run seed:demo   # เพื่อนร่วมชั้นตัวอย่างสำหรับหน้าอันดับ (ไม่บังคับ)
npm run dev         # API ที่ :3001 + เว็บที่ http://localhost:5173
npm test            # unit test: assembler, CPU, C compiler, MIPS→C, Z80, ตัวตรวจโจทย์
npm run build       # typecheck ทั้งเว็บและ server แล้ว build ลง dist/
npm start           # production: server เดียวเสิร์ฟทั้ง API และ dist/ (PORT, ค่าเริ่มต้น 3001)
```

ฐานข้อมูลอยู่ที่ `data/mipslab.db` (เปลี่ยนได้ด้วย `MIPSLAB_DB`)

## เข้าสู่ระบบด้วย Google (ทางเดียวที่ใช้ได้)

1. Google Cloud Console → APIs & Services → Credentials → Create credentials → OAuth client ID → ประเภท **Web application**
2. Authorized JavaScript origins ใส่ `http://localhost:5173` (และโดเมนจริงตอน deploy)
3. คัดลอก `.env.example` เป็น `.env` แล้วใส่ `GOOGLE_CLIENT_ID=...` จากนั้นรัน `npm run dev` ใหม่

**ทดลองโดยไม่ต้องตั้งค่า Google:** ตอนรัน `npm run dev` หน้าล็อกอินจะมีปุ่ม "เข้าแบบทดลอง (dev)" เข้าเป็นบัญชี `dev` (SEC 1) ได้ทันที — ปุ่มนี้ไม่มีใน `npm start` (บังคับเปิดได้ด้วย `MIPSLAB_DEV_LOGIN=1` ห้ามใช้บนเครื่องจริง)

ล็อกอินครั้งแรกระบบสร้างบัญชีให้อัตโนมัติ (ไม่มีระบบรหัสผ่าน) — ถ้าอีเมลเป็นแบบ `6601234567@…` จะใช้เลขนั้นเป็นรหัสนักศึกษา ถ้าอีเมลตรงกับที่อาจารย์ลงทะเบียนไว้จะเข้าบัญชีนั้น · `MIPSLAB_GOOGLE_DOMAIN` จำกัดให้ใช้ได้เฉพาะโดเมนเดียว · server ตรวจลายเซ็น ID token กับกุญแจของ Google เองทุกครั้ง

## ห้องเรียน (แยกนักศึกษาตามกลุ่มและภาคเรียน)

ห้อง = กลุ่มเรียน 1 กลุ่มใน 1 ภาคเรียน เช่น `SEC 1 · 2/2569`

1. อาจารย์กด **สร้างห้อง** ในหน้า `/teacher` (ใส่ชื่อห้อง เลือกปีการศึกษา พ.ศ. และภาคเรียน) ระบบจะสุ่ม**รหัสเข้าห้อง** 6 ตัวให้ เช่น `K7Q2XM` · หลายกลุ่มในภาคเรียนเดียวกัน (SEC 1, SEC 2) สร้างพร้อมกันได้
2. **ต้องลบห้องเทอมก่อนก่อน จึงจะเปิดห้องเทอมใหม่ได้** — ถ้ายังมีห้องของภาคเรียนก่อนค้างอยู่ ฟอร์มจะแจ้งรายชื่อห้องเก่าพร้อมปุ่มลบ
3. **ลบห้อง = ล้างข้อมูลนักศึกษาในห้องนั้น** (คะแนน โจทย์ที่ส่ง โค้ดร่าง เฉลยที่เปิด) บัญชียังอยู่ แต่ต้องใส่รหัสห้องใหม่ คนลงเรียนซ้ำจึงเริ่มจากศูนย์ทุกปี และไม่มีการเก็บประวัติห้องเก่า · ก่อนลบ ระบบสำรองฐานข้อมูลไว้ที่ `data/backups/` ให้อัตโนมัติ (กู้คืนได้ด้วยการเอาไฟล์นั้นมาแทน `data/mipslab.db` ตอนปิด server)
4. **นักศึกษาต้องอยู่ในห้องที่เปิดอยู่ก่อนถึงจะใช้งานได้** — ถ้ายังไม่มีห้อง หรือห้องเดิมถูกปิด/ลบไปแล้ว จะเจอหน้า "เข้าห้องเรียนก่อนเริ่มใช้งาน" แทนทุกหน้า ทำ 2 ขั้นตามลำดับ:
   1. ใส่**รหัสนักศึกษา** (บังคับ · ตั้งได้ครั้งเดียว) — ถ้าอาจารย์มีรายชื่อเขาแล้ว (ดูข้อ 5) จะเข้าห้องให้ทันที ไม่ต้องทำขั้น 2
   2. ใส่**รหัสเข้าห้อง**ที่อาจารย์แจก (server ไม่รับรหัสห้องจากบัญชีที่ยังไม่มีรหัสนักศึกษา)
5. ปุ่ม **เพิ่มรายชื่อ** ในแต่ละห้อง: วางรหัสนักศึกษาหรืออีเมลบรรทัดละคน (คัดลอกคอลัมน์จาก Excel ได้)
   - คนที่มีบัญชีแล้วย้ายเข้าห้องนี้ทันที
   - คนที่ยังไม่มีบัญชี จะเข้าห้องนี้เองตอนล็อกอินครั้งแรก (จับคู่จากอีเมล) หรือตอนตั้งรหัสนักศึกษา · ห้องแสดงจำนวน "รอล็อกอิน"
6. หน้าอาจารย์กรองรายชื่อได้ตามห้องหรือทั้งปีการศึกษา · กระดานอันดับ "ห้องของฉัน" เทียบเฉพาะคนในห้องเดียวกัน
7. **ปิดห้อง** = หยุดรับคนเข้าด้วยรหัส (ข้อมูลไม่หาย เปิดใหม่ได้) · ถ้ารหัสหลุดออกไป กดสุ่มรหัสใหม่ได้
8. หน้าอาจารย์**อัปเดตรายชื่อแบบสด**ผ่าน WebSocket (`/api/ws` พอร์ตเดียวกับ API · เฉพาะบัญชีอาจารย์) — นักศึกษาส่งโจทย์ เข้าห้อง หรือสมัครใหม่ รายชื่อเปลี่ยนเองภายในไม่ถึงวินาที มุมขวาบนขึ้น "● สด" · ถ้าเน็ตหลุดจะต่อใหม่เอง · ถ้าวางหลัง reverse proxy (nginx ฯลฯ) ต้องเปิดให้ส่งต่อ WebSocket ที่ `/api/ws` ด้วย
9. ปุ่ม **Excel** / **Word** / **PDF** ข้างตัวกรอง: ส่งออกรายชื่อนักศึกษาพร้อมคะแนน (ลำดับ · รหัส · ชื่อ · ห้อง · ผ่านกี่ข้อ · งานตรงเวลา · คะแนน) ตามตัวกรองที่เลือกอยู่ เรียงตามรหัสนักศึกษา · Excel เป็นไฟล์ .csv (UTF-8) เปิดด้วย Excel/Google Sheets ได้ภาษาไทยไม่เพี้ยน · Word ใช้ฟอนต์ TH Sarabun New · PDF จะเปิดหน้าต่างพิมพ์ ให้เลือก "บันทึกเป็น PDF"
10. **ลบห้องต้องดาวน์โหลดคะแนนก่อน** — ห้องที่มีนักศึกษา ปุ่มลบจะกดได้หลังดาวน์โหลดคะแนนของห้องนั้น (Excel/Word/PDF) อย่างน้อยหนึ่งไฟล์
11. **มอบหมายโจทย์** (ปุ่มในแต่ละห้อง): เลือกข้อและกำหนดส่ง (วัน-เวลา) · นักศึกษาเห็น "งานที่ได้รับมอบหมาย" พร้อมป้าย ส่งภายใน / เหลือ x ชม. / เลยกำหนด / ส่งตรงเวลา / ส่งช้า · หน้าอาจารย์มีคอลัมน์ "งาน" = ส่งตรงเวลา/ที่มอบหมาย (คะแนนปกติยังได้แม้ส่งช้า)
12. **กดชื่อนักศึกษา** → ดูรายข้อ: ผ่านเมื่อไร ลองกี่ครั้ง ค้างข้อไหน กำหนดส่ง
13. **สถิติรายข้อ**: ผ่านกี่คน/ลองกี่คน ตามนักศึกษาที่กรองอยู่ พร้อมเตือนข้อที่ผ่านน้อย
14. **ตรวจโค้ดคล้ายกัน**: หาคู่ที่ส่งโค้ดเกือบเหมือนกัน (≥ 85%) ในข้อเดียวกัน — ตัดคอมเมนต์ ช่องว่าง และชื่อ label/ตัวแปรออกก่อนเทียบ ข้อสั้นมากถูกข้าม · เปิดดูโค้ดสองฝั่งก่อนตัดสินเสมอ
15. **ประวัติการทำงานของอาจารย์**: สร้าง/แก้/ปิด/ลบห้อง เพิ่มรายชื่อ มอบหมายโจทย์ แก้บัญชี เพิ่มอาจารย์ (100 รายการล่าสุด)
16. server บังคับเรื่องห้องด้วย: นักศึกษาที่ไม่มีห้องเรียก API โจทย์/อันดับไม่ได้ · ใส่รหัสห้องผิด 10 ครั้ง ต้องรอ 10 นาที
17. **สำรองฐานข้อมูลอัตโนมัติวันละครั้ง** ที่ `data/backups/daily-YYYY-MM-DD.db` (เก็บ 14 วันล่าสุด) และก่อนลบห้องทุกครั้ง · กู้คืน: ปิด server แล้วเอาไฟล์สำรองมาแทน `data/mipslab.db`

## จัดการบัญชี (สำหรับอาจารย์ · ไม่บังคับ)

`<รหัสเข้าห้อง>` คือรหัสห้องจากหน้าอาจารย์ ถ้ายังไม่ใส่ห้องให้ใช้ `""`

```bash
npm run user -- add 6601234567 "ชื่อ นามสกุล" K7Q2XM someone@uni.ac.th   # ลงทะเบียนล่วงหน้า
npm run user -- import students.csv        # studentId,name,รหัสเข้าห้อง,email ต่อบรรทัด
npm run user -- email 6601234567 someone@uni.ac.th
npm run user -- class 6601234567 K7Q2XM    # ย้ายเข้าห้อง
npm run user -- classes                    # ดูห้องทั้งหมดและรหัสเข้าห้อง
npm run user -- teacher somchai.j "อ.สมชาย ใจดี"  # สร้างบัญชีอาจารย์ (ไม่ใส่รหัสผ่าน = สุ่มให้แล้วพิมพ์ออกมา)
npm run user -- password somchai.j             # ตั้งรหัสผ่านอาจารย์ใหม่ (ลืมรหัส)
npm run user -- list
npm run user -- remove 6601234567
```

## บทบาท: นักศึกษา / อาจารย์

- **นักศึกษา** — เข้าด้วย Google (สร้างบัญชีให้อัตโนมัติ) · ทำโจทย์ ติดอันดับ แก้ชื่อได้เอง เข้าห้องเรียนด้วยรหัสจากอาจารย์ และตั้งรหัสนักศึกษาได้ครั้งเดียว (หลังจากนั้นอาจารย์แก้ให้)
- **อาจารย์** — เข้าด้วย**ชื่อผู้ใช้และรหัสผ่าน** (แท็บ "อาจารย์" ในหน้าล็อกอิน) · มีเมนู "อาจารย์" (`/teacher`) สร้าง/ปิดห้องเรียน ดูรายชื่อตามห้องหรือปีการศึกษา คะแนน การใช้งานล่าสุด แก้ชื่อ/รหัส/ห้องของนักศึกษา เพิ่มบัญชีอาจารย์ และตั้งรหัสผ่านใหม่ให้อาจารย์ท่านอื่น · ไม่อยู่ในกระดานอันดับ · เปิดเฉลยได้โดยไม่เสียคะแนน
- สร้างบัญชีอาจารย์คนแรกด้วย `npm run user -- teacher <ชื่อผู้ใช้> "<ชื่อ>"` · รหัสผ่านเก็บแบบ scrypt hash · ใส่รหัสผิด 5 ครั้งล็อก 10 นาที · ตอน `npm run dev` มีปุ่ม "เข้าแบบทดลองเป็นอาจารย์ (dev)"

## โครงสร้าง

- `src/lib/mips/` — assembler (คำสั่ง MIPS32 จำนวนเต็ม + pseudo-instruction + directive `.data`/`.word`/`.asciiz` ฯลฯ), CPU ที่อธิบายแต่ละขั้นเป็นภาษาไทยและย้อนกลับได้, decoder
- `src/lib/cc/` — `compile.ts` คอมไพเลอร์ C ชุดย่อย → MIPS (ฟังก์ชัน, recursion, pointer/array, global) · `lift.ts` แปลง MIPS → C
- `src/lib/z80/` — assembler + emulator Z80 · `board.ts` pinout, net และการตรวจวงจร · `machine.ts` ต่อ emulator เข้ากับวงจร (memory map, OUT/IN)
- `src/lib/grader.ts` — ตัวตรวจโจทย์ (ใช้ทั้งฝั่ง server)
- `src/data/problems.ts` — คลังโจทย์ 24 ข้อ พร้อมเคสทดสอบ เคสซ่อน คำใบ้ และเฉลย · เพิ่มโจทย์ใหม่ที่ไฟล์นี้ (มี test ตรวจว่าเฉลยทุกข้อผ่านเคสของตัวเอง) · ข้อ 14–24 อยู่ใน `src/data/basicProblems.ts`
- `server/` — API (Express), ฐานข้อมูล, คะแนน/อันดับ, CLI จัดการบัญชี
- `src/screens/`, `src/components/` — หน้าจอและ component (เช่น `CodeEditor`, `Datapath`)
