# Classroom และ data tables

นำ workflow จาก `origin/mips-lab-web` commits `b5ce5b7` และ `8a82064` มาใช้กับ Cloudflare Pages Functions / D1 ของ branch ปัจจุบัน ไม่ได้เปลี่ยนกลับไปใช้ Express, SQLite, Google login หรือ WebSocket server ของ branch เพื่อน

## ใช้งาน

- หน้าอาจารย์มีแท็บห้องเรียน ภาพรวม โปรเจกต์ Z80 นักศึกษาและคะแนน และจัดการโจทย์
- สร้างห้องแยกชื่อ / ปีการศึกษา / ภาคเรียน รหัสเข้าห้อง 6 ตัว คัดลอกหรือสุ่มใหม่ได้
- วางรหัสนักศึกษา/อีเมลทีละคนได้สูงสุด 500 คนต่อครั้ง บัญชีที่มีอยู่ย้ายทันที คนที่ยังไม่มีบัญชีจะเข้าห้องอัตโนมัติเมื่ออาจารย์สร้างบัญชีให้หรือเข้าสู่ระบบ หลังจากนั้นรายการรอของคนนั้นจะถูกนำออก
- การเพิ่มบัญชีนักศึกษาและแก้บัญชีเลือกห้องที่เปิดอยู่ได้ นักศึกษาใช้รหัสห้องเพื่อเข้าหรือย้ายห้องในหน้าตั้งค่าได้ คะแนนเดิมคงอยู่
- มอบหมายโจทย์ที่เผยแพร่แล้วให้แต่ละห้องและตั้งกำหนดส่งรายข้อ นักศึกษาเห็นงานพร้อมกำหนดส่งและสถานะตรงเวลาในหน้าโจทย์
- กำหนดส่งของงานรายห้องใช้ติดตามความตรงเวลา ยังคงส่งหลังเวลานี้ได้ ส่วนวันปิดรับที่ตั้งในตัวโจทย์เดิมยังเป็นวันปิดรับจริง
- สั่งโปรเจกต์บอร์ด Z80 ให้ห้อง นักศึกษากดส่งให้อาจารย์จากหน้าบอร์ด อาจารย์เปิดวงจรพร้อมโค้ดในแท็บใหม่ ดาวน์โหลด JSON ให้คะแนน 0–1000 และเขียนความเห็นได้ งานที่ตรวจแล้วส่งทับไม่ได้ จนกว่าอาจารย์ล้างคะแนนและความเห็นให้กลับเป็นยังไม่ตรวจ
- คะแนนโปรเจกต์แสดงแยกตามงาน ไม่บวกซ้ำกับคะแนนผ่านโจทย์ใน leaderboard
- ปิดห้องเก็บรายชื่อ คะแนน งาน และประวัติไว้ เปิดกลับได้ การลบห้องทำได้เฉพาะห้องที่ไม่มีนักศึกษาและโปรเจกต์ ต่างจาก branch เพื่อนที่ล้างผลงานนักศึกษาตอนลบห้อง
- อันดับในห้องแยกด้วย class ID จึงไม่ปนกันแม้ชื่อห้องเหมือนกันแต่คนละเทอม
- Dashboard อัปเดตทุก 15 วินาทีขณะเปิดแท็บ ไม่รบกวนฟอร์มบัญชี/โจทย์ที่กำลังแก้ และมีปุ่มรีเฟรช

ตารางรายชื่อและคะแนน ผลโจทย์ คะแนนรายข้อ ความคืบหน้า งานโปรเจกต์ที่ส่ง และประวัติอาจารย์ใช้ `DataTable` ร่วมกัน: ค้นหาหลายคำ เรียงข้อมูลตัวเลข/ภาษาไทย แบ่งหน้า 10/25/50/100 แถว เลือกคอลัมน์ และส่งออก CSV ของทุกแถวที่กรองไว้ ไม่ใช่เฉพาะหน้าปัจจุบัน รองรับการเลื่อนตารางบนมือถือ พร้อมสถานะว่าง/กำลังโหลดและการใช้งานด้วยคีย์บอร์ด รายชื่อที่กรองส่งออก Word หรือเปิดพิมพ์/บันทึก PDF ได้ด้วย

## ติดตั้ง schema

```sh
npm ci
npm run db:migrate:local
npm run build
npm test
npm run test:e2e
```

`0002_classroom.sql` ย้ายกลุ่มเรียนเดิมไปเป็นห้องตามปีการศึกษาที่ตั้งไว้และภาคเรียนปัจจุบัน โดยคง users / solves / attempts / drafts เดิม การสร้างบัญชีผ่าน API เดิมที่ส่ง `section` ยังรองรับ แต่ UI ใหม่ใช้ `classId` ชัดเจน

ก่อนนำขึ้น production ต้องใช้ `npm run db:migrate:remote` แล้ว deploy bundle ด้วย `npm run deploy` ห้าม seed บัญชีทดสอบจาก e2e ขึ้น production

`e2e/classroom-integration.spec.ts` ตรวจ API กับ D1 จริงบนเครื่อง ครอบคลุมสิทธิ์อาจารย์/นักศึกษา ห้องคนละเทอม รายชื่อรอ กำหนดส่ง งานต่างห้อง ส่งงาน ตรวจคะแนน ล็อกงานที่ตรวจแล้ว ปิด/เปิดห้อง คะแนนไม่หาย ส่งออกไฟล์ และตารางบน desktop/mobile
