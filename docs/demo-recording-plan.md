## ตัวอย่างสำหรับโชว์ฟีเจอร์ C ใหม่

เลือกจากเมนู **โค้ดตัวอย่าง** บนหน้าโค้ด ไม่ต้องพิมพ์ใหม่ระหว่างอัด

| ตัวอย่าง | สิ่งที่เน้น | ผลลัพธ์ |
|---|---|---:|
| `switch` | case 2 ทำงานต่อเข้า case 3 เพราะไม่มี `break` | **25** |
| `sizeof` | คำนวณจำนวนสมาชิกจากขนาด matrix และแถว | **6** |
| `&ตัวแปร` | ฟังก์ชันอื่นแก้ตัวแปรผ่าน pointer | **5** |
| อาร์เรย์ 2 มิติ | ส่งแถวที่สองไปหาผลรวม | **15** |

เลือกหนึ่งตัวอย่างอธิบายให้ชัด ส่วนตัวอย่างที่เหลือแสดงโค้ดและผลลัพธ์สั้น ๆ เพื่อคุมเวลา

## โจทย์ที่ใช้เดโมการตรวจคำตอบ

### ข้อมูลโจทย์

- **ชื่อ:** Demo — บวกเลขสองจำนวน
- **ภาษา:** C
- **ชื่อฟังก์ชัน:** `add`
- **พารามิเตอร์:** `a` ผ่าน `a0` และ `b` ผ่าน `a1`
- **ผลลัพธ์:** ผลรวมผ่าน `v0`
- **คะแนนพื้นฐาน:** 20
- **คำอธิบาย:** เขียนฟังก์ชัน `add` เพื่อคืนผลรวมของจำนวนเต็มสองจำนวน

### เคสทดสอบ

| ประเภท | Input | Expected |
|---|---|---|
| แสดงให้นักศึกษา | `a = 2, b = 3` | `v0 = 5` |
| เคสซ่อน | `a = -4, b = 9` | `v0 = 5` |

หากกรอกผ่านช่อง JSON ใช้ข้อมูลนี้:

```json
[
  { "args": [2, 3], "expect": { "v0": 5 } },
  { "args": [-4, 9], "expect": { "v0": 5 }, "hidden": true }
]
```

### ขั้นที่ 1: โค้ดผิดเพื่อแสดงผลทดสอบ

```c
int add(int a, int b) {
    return a - b;
}
```

กด **ทดสอบ** แล้วชี้ให้เห็นว่า input `2, 3` ควรได้ `5` แต่โค้ดให้ `-1`

ประโยคพูด:

> “ผลทดสอบแสดงข้อมูลเข้า ผลที่คาดหวัง และผลจากโค้ดของเรา ทำให้นักศึกษาหาจุดผิดและแก้คำตอบได้”

### ขั้นที่ 2: แก้โค้ดและส่งคำตอบ

```c
int add(int a, int b) {
    return a + b;
}
```

ใช้โค้ดนี้เป็นเฉลยตอนอาจารย์สร้างโจทย์ด้วย จากนั้นฝั่งนักศึกษากด **ส่งคำตอบ** เพื่อให้ตรวจรวมเคสซ่อน

ถ้าเป็นการส่งครั้งแรกของโจทย์ใหม่ จะได้ **20 + โบนัส 5 = 25 คะแนน** การทดสอบโค้ดผิดก่อนหน้านี้ไม่ทำให้เสียโบนัส เพราะยังไม่ได้ส่งคำตอบ

ประโยคพูด:

> “เมื่อส่งคำตอบ ระบบตรวจทั้งเคสที่เห็นและเคสซ่อนบน server แล้วบันทึกคะแนน นักศึกษาไม่ได้เป็นผู้กำหนดคะแนนเอง”

หมายเหตุ: ถ้ากด **ทดสอบ** แล้วผ่านทุกเคสที่แสดง หน้าโจทย์จะส่งคำตอบต่อให้อัตโนมัติ สำหรับคลิปนี้จึงใช้ปุ่มทดสอบกับโค้ดผิด และใช้ปุ่มส่งคำตอบหลังแก้เสร็จ เพื่อให้ลำดับชัดเจน

## จุดที่ควรให้เห็นตอนดูผลฝั่งอาจารย์

1. เลือกห้อง **ComArch Demo** และค้นหาบัญชีนักศึกษาที่ใช้เดโม
2. แสดงรหัสนักศึกษา ห้องเรียน และชั้นปีที่คำนวณตามปีการศึกษาที่ตั้งไว้
3. เปิดผลรายคน ให้เห็นโจทย์ที่ผ่าน คะแนน และประวัติทดสอบ/ส่งคำตอบ
4. เปิดดูโค้ดที่นักศึกษาส่ง
5. ส่งออก CSV เพื่อแสดงว่านำผลคะแนนไปใช้ต่อได้
6. รีเฟรชหน้า แล้วชี้ว่าข้อมูลยังคงอยู่

ถ้าต้องการนำเสนอระบบทั้งโครงการ ให้เพิ่มช่วงนี้หลังการตรวจโจทย์ C:

4. นักศึกษากดส่งงานให้อาจารย์
5. อาจารย์เปิดวงจรและโค้ดที่ส่ง แล้วให้คะแนนและความเห็น
